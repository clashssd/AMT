Прочитай файл `DESIGN_UPDATE.md` в корне проекта целиком и следуй ему.

Задача: $ARGUMENTS

Если аргумент не указан — выполни все фазы подряд:
1) изучи приложение;
2) проведи аудит, включая поля и белые плашки;
3) выполни фазы 1–9;
4) после каждой фазы — проверка и коммит;
5) в конце — отчёт по чек-листу.

Правила:
- только vanilla HTML/CSS/JS, без новых зависимостей;
- не трогай backend, Python и Electron main;
- все цвета, фоны, поля, карточки, модалки и кнопки должны быть токенами и настраиваться в теме (дефолт + кастом);
- работай только во frontend/ и docs/, если задача не требует иного;
- в конце покажи `git diff --stat`, вывод `npm run check:design` и список проверок.

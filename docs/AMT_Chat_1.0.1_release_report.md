# Отчёт о релизе AMT Chat v1.0.1

**Дата:** 2026-11-25  
**Формат:** NSIS-инсталлятор (Windows)  
**Портативный размер:** ~138 МБ (ZIP-архив `AMT-Chat-1.0.1.zip`)  
**Кодировка отчёта:** UTF-8

## 1. Состав релиза

| Файл | Назначение |
|---|---|
| `AMT-Chat-1.0.1/AMT Chat Setup 1.0.1.exe` | NSIS-инсталлятор (внутри: Electron + Python-бэкенд + фронтенд + расширения) |

## 2. Новый функционал в v1.0.1

### 2.1. Универсальный поиск браузера

Ранее ИИ искал браузеры по жёстко заданному списку из 4 штук (Chrome, Firefox, Edge, Brave). Теперь поиск универсальный — 5 стратегий:

1. Реестр Uninstall (`HKLM`/`HKCU`, ключи `Uninstall` + `UninstallString`/`DisplayIcon`)
2. Общие каталоги установки (`C:\Program Files\...`, `C:\Program Files (x86)\...`, `%LOCALAPPDATA%\Programs\...`)
3. Start Menu `.lnk`-ярлыки (`%APPDATA%\Microsoft\Windows\Start Menu\Programs\`)
4. PATH (`$PATH` — ищем `*.exe` с известными именами браузеров)
5. По имени (прямой запуск `chrome.exe` / `firefox.exe` / `msedge.exe` / `brave.exe` / `vivaldi.exe` / `opera.exe` / `yandex.exe` / `arc.exe` / `kometa.exe` и др.)

Поддерживаемые браузеры: Chrome, Firefox, Edge, Brave, Vivaldi, Opera, Arc, Chromium, Kometa, Yandex, и любые другие `.exe`-браузеры, установленные на системе.

### 2.2. Автоопределение браузера по умолчанию

При первом запуске (или при пустом `settings.json`) ИИ читает:

- `HKCU\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\https\UserChoice\Program`
- `HKCR\http\shell\open\command` (дефолтный браузер Windows)

Результат сохраняется в `settings.json` → `default_browser`. При запросе «открой в браузере» без указания конкретного браузера — используется запомнившийся дефолт.

### 2.3. Взаимодействие с окнами (4 новых SYS-токена)

| Токен | Действие | Пример |
|---|---|---|
| `[[SYS:window_focus\|app]]` | Привести окно на передний план | `[[SYS:window_focus\|code]]` — VS Code |
| `[[SYS:window_send_keys\|app\|text]]` | Напечатать текст в окно (через буфер обмена, поддержка кириллицы) | `[[SYS:window_send_keys\|code\|print("hello")]]` |
| `[[SYS:window_click\|x\|y\|app]]` | Клик в координаты окна (или всего экрана) | `[[SYS:window_click\|500\|300]]` |
| `[[SYS:window_screenshot\|app]]` | Снимок окна (PrintWindow) или всего экрана (BitBlt) | `[[SYS:window_screenshot\|code]]` |

ИИ может взаимодействовать с ЛЮБЫМ запущенным приложением: VS Code, Word, браузер, игра и т.д.

### 2.4. Структурированное распознавание страниц (page_recon)

Из HTML извлекаются до 100 элементов:

- **Кнопки** — текст, `id`, `class`
- **Поля ввода** — `type`, `id`, `placeholder`
- **`textarea`** — `id`, `rows`, `cols`
- **Видео** — `src`, `controls`
- **Картинки** — `src`, `alt`
- **`iframe`** — `src`
- **`select`** — варианты (`<option>`)

ИИ видит структуру страницы и может целенаправленно взаимодействовать: «нажми кнопку „Смотреть“», «найди второе видео и запусти его».

### 2.5. Повторные попытки (retry)

Если действие не сработало (приложение не найдено, страница не загрузилась) — ИИ пробует альтернативную стратегию (другой способ запустить приложение, другой браузер, другой подход к скриншоту).

### 2.6. Медиа-генерация (Agnes auto-detect)

- Автодетект Agnes по `base_url` (`https://apihub.agnes-ai.com/v1`)
- Agnes-специфичные параметры: `return_base64: true` для картинок, `seconds: "5"` для видео
- Если base_url не содержит `/v1` — дописывается автоматически
- Поддержка `[[GEN:image|…]]`, `[[GEN:video|…]]`, `[[GEN:audio|…]]`, `[[GEN:file|…]]`

### 2.7. Ошибки API — дружелюбные сообщения

Вместо сырого Python-исключения пользователь видит:

- `ConnectError` → «Не удалось подключиться к бэкенду. Запустите `python backend/main.py`.`
- `401`/`403` → «API-ключ отклонён (401/403). Проверьте ключ в настройках.»
- `404` → «Адрес API не найден (404). Проверьте base_url в настройках.»

### 2.8. `[[SYS:window_click]]` — вал��дация координат

Если `x`/`y` не целые числа — ИИ получает `[Некорректные координаты: x=…, y=…. Укажите целые числа.]` вместо краха.

## 3. Установка

### 3.1. Быстрая установка (одним файлом)

1. Распакуйте `AMT-Chat-1.0.1.zip`
2. Запустите `AMT-Chat-1.0.1\AMT Chat Setup 1.0.1.exe`
3. Если Windows показывает SmartScreen: «Подробнее» → «Выполнить в любом случае»
4. Дождитесь завершения установки (1–2 минуты)
5. Запустите AMT Chat из меню Пуск
6. В настройках укажите API-ключ провайдера (картинки/видео/текст)
7. Готово

> Все зависимости (Python, Node.js, Electron, бэкенд) уже включены в установщик — ставить их **не нужно**.

### 3.2. Для разработчика (сборка с исходников)

```powershell
git clone https://github.com/clashssd/AMT.git
cd AMT
powershell -ExecutionPolicy Bypass -File scripts\bootstrap_and_build.ps1
```

Скрипт автоматически:
1. Проверит Python 3.12+ и Node.js (установит через `winget` при отсутствии)
2. Создаст `backend/.venv` и поставит Python-зависимости
3. Поставит Node-зависимости
4. Соберёт `AMT Chat.exe` (портативный) и `AMT Chat Setup <версия>.exe` (NSIS)
5. Применит патч иконки в готовом `.exe`

Подробности — в `docs/BUILD.md`, `docs/SETUP.md`.

## 5. Известные ограничения

- **SmartScreen** — приложение не подписано code-signing сертификатом. При первом запуске Windows покажет предупреждение. Обход: «Подробнее» → «Выполнить в любом случае». Портативная копия (`win-unpacked\AMT Chat.exe`) обычно SmartScreen не блокирует.
- **NSFW-контент** — доступен только при активном jailbreak-режиме (явные правила в системном промпте). Ответственность за использование лежит на пользователе.
- **Jailbreak** — обход фильтров модели. Не является официальным API-фичей провайдеров.

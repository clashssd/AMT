## Как заполнить

1. **Settings → General → About**
   - Scroll down to "About" section
   - **Description:** вставьте About EN (320 chars)
   - **Website:** (опционально) `https://clashssd.github.io/AMT/` (если Pages запущен) или оставить пустым
   - **Topics:** впишите 20 topics из списка (через запятую)
   - **Language:** (если есть) Python
   - Сохранить

2. **Settings → Social preview**
   - **Title:** AMT Chat — local AI assistant
   - **Description:** (вставьте Social Preview Text)
   - **Image:** (если есть) `docs/assets/social-preview.png` (создать позже в Блоке 2)
   - Сохранить

3. **Settings → General → About → Website** (если Pages запущен)
   - Впишите `https://clashssd.github.io/AMT/`
   - Сохранить

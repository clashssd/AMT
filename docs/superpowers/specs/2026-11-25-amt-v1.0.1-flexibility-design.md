# AMT Chat v1.0.1 — Design

## Intent
Make AMT Chat fully flexible: detect & remember user's default browser, launch any browser/app without hardcoded paths, inspect page DOM structure, and interact with running app windows (focus, keys, clicks, screenshots).

## Goals
1. **Default browser detection** — on first run, read Windows registry (UserChoice + HKCR fallback), store in settings.json as `default_browser`
2. **Any-browser launch** — replace the hardcoded 4-browser dict with a universal search: registry Uninstall keys → common install paths → Start Menu .lnk → PATH. Support any browser name (vivaldi, opera, arc, chromium, etc.)
3. **Structured page recon** — enhance `page_recon` to also extract structured elements: buttons, inputs, videos, images, iframes, with their text/context so LLM can reason about what's on the page
4. **Window interaction** — new tools: `window_focus(app)`, `window_send_keys(text)`, `window_click(x,y)`, `window_screenshot()` — Win32 ctypes + SendInput for keystrokes
5. **Remove hardcoded paths** — audit all code for hardcoded browser names, app names, paths; make everything discovered dynamically
6. **Build v1.0.1** — change version, run PyInstaller + electron-builder

## Non-goals
- Full RPA / robotic process automation (that's a much bigger project)
- Mobile / cross-platform window interaction (Windows only for now)
- OCR on screenshots (LLM can see via vision, no need)

## Approach
- **Default browser**: Windows registry `HKCU\Software\Microsoft\Windows\Shell\Associations\UrlAssociations\https\UserChoice` → `ProgId` → map to browser name. Fallback: `HKCR\http\shell\open\command`. Detect on first launch, store in settings. When `open_url` is called without browser param, use the remembered default.
- **Universal browser search**: `_find_browser(name)` method that searches: 1) registry Uninstall keys (matches DisplayName), 2) common install dirs (glob `*<name>*.exe`), 3) Start Menu .lnk, 4) PATH. This replaces the hardcoded 4-browser dict.
- **Structured page recon**: parse HTML with regex for structured elements — `<button>`, `<input>`, `<video>`, `<img>`, `<iframe>`, `<select>`, `<textarea>` — return them in an `elements` array alongside text. LLM can then say "I see a video player, let me interact with it."
- **Window interaction**: new `WindowController` class using ctypes (user32, kernel32): `EnumWindows` to find windows by process name, `SetForegroundWindow` (with AttachThreadInput trick), `SendInput` for keystrokes, `SetCursorPos`+`mouse_event` for clicks, `BitBlt` or PrintWindow for screenshots. Register 4 new tools in the dispatcher.
- **Retry logic**: already exists in plan executor (`MAX_PLAN_RETRIES=3`). The multi-strategy launch_app already retries. Good enough — no changes needed there.

## Files to modify
- `backend/ai_engine/desktop_tools.py` — universal browser search, structured page_recon, window interaction tools
- `backend/ai_engine/sysinteraction.py` — update seed agent prompts to document new tools, add new SYS tokens
- `backend/main.py` — detect default browser on startup, store in settings
- `package.json` — version → 1.0.1
